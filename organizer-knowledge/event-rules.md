# Event Rules — Hedera x402 Builder Sprint

## Mandatory Requirements

- **Public open-source GitHub repository** — Auto-disqualification if missing.
- **Demo video under five minutes** showing the complete end-to-end flow and on-chain transactions — Auto-disqualification if missing or over the time limit.
- **HashScan links** to relevant Hedera Testnet transactions — Critical if missing.
- **Completed submission form** — Auto-disqualification if not submitted.
- **x402 payment flow** — The project must demonstrate a working HTTP 402 → payment → response cycle.

## Required Technologies

- **Hedera** (Testnet) for settlement.
- **x402 protocol** for the payment negotiation layer.

## Restrictions

- No mainnet transactions are accepted as evidence.
- No closed-source or proprietary payment rails as the primary settlement mechanism.
- The demo video must show the flow actually working, not just a narrated slide deck.

## Dates

- Bounty runs: July 13 through July 31.
- Submission deadline: July 31 at 11:59 PM ET.
- No extensions unless officially announced.

## Submission Format

- Google Form is the canonical submission endpoint.
- Repository link, demo video link, and HashScan transaction link(s) are required fields.
- A README must exist in the repository.

## Repository Requirements

- Public repository.
- README with project description.
- Installation instructions.
- Execution instructions.
- License is recommended but not mandatory for submission.
- Links to demo video and transaction evidence should be present in the README or submission form.

## Video Limits

- Maximum duration: 5 minutes (300 seconds).
- Must include audio narration or explanation.
- Must show the HTTP 402 initial response.
- Must show the payment payload.
- Must show the paid retry and final resource response.
- Must show on-chain transaction evidence (HashScan or equivalent).
